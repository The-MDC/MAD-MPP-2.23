# PROJECTS/

Canonical home for working folders. This repo is the single source of truth — nothing here
should exist only on a local disk or in a Cowork folder.

| Folder | Holds |
|---|---|
| `platform/` | MPP architecture, product decisions, feature specs |
| `investors/` | Pitch decks, VC outreach, data-room drafts, diligence responses |
| `marketing/` | Website copy, content calendar, campaigns, social |
| `smart-contracts/` | Solidity design notes, audit prep, deployment records |
| `tokenomics/` | $MADx design, fee modelling, staking-tier reconciliation |

Shipped code lives in `app/`, `contracts/`, `backend-node/`, `verify/`, `master-maths/`.
These folders are for the thinking that produces it.
