# Canonical Handoff & Briefing Templates

## Handoff Format (use exactly)

**Handoff to [Specialist Agent Name]**:
- Task: [clear, single responsibility description]
- Context: [relevant prior state, files, commit SHAs, open TODOs]
- Required tools: [list of tools / skills needed]
- Expected output: [concrete deliverable]
- Session ID: [current session or PR number]
- Proprietary gate status: [cleared / gated / awaiting MADdegen auth]
- Related files: [paths under .agents/ or verify/]

## Progress.md Update Pattern
After every major step:
```
## [YYYY-MM-DD HH:MM]
- Action: ...
- Result: ...
- Next: ...
- Blockers: ...
```

## BRIEFING.md Structure
- Role & goals
- Current open TODOs from SESSION_HANDOFF.md
- Proprietary boundaries
- Success criteria
- Handoff expectations
