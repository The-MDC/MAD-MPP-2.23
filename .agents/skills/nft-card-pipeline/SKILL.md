# NFT Card Pipeline

## Overview

End-to-end management of the 152-card MAD Gambit NFT art system: serial-based tiling via cardArtUrl, rarity-aware holographic / faction-wash treatment, gen-card-art.mjs regeneration, FLUX LoRA pipeline (MAD-Card-Art-Generator), and Drive-sourced original assets. 25/152 currently committed.

## Proprietary Gate

Card art source files and LoRA weights are proprietary. Never redistribute raw art or generator weights. High-level pipeline and public/cards structure are fine.

## When to Activate

- “card art”, “serial”, “rarity”, “NFTCards”, “open pack”, “cardArtUrl”, “gen-card-art”, “holographic”, “faction wash”, or any request touching verify/lib/card-art.ts, nft-card.tsx, public/cards/, or the MAD-Card-Art-Generator repo.

## Core Instructions

1. **Serial Tiling**
   - cardArtUrl(serial) in verify/lib/card-art.ts maps serial → art path.
   - CARD_ART_COUNT regenerated by verify/scripts/gen-card-art.mjs after any public/cards change.
   - Current: 25 of 152 real cards (001–025.png + manifest.json).

2. **Rarity Treatment (nft-card.tsx)**
   - Highest rarity tiers: pure holographic art.
   - Lower tiers: faction-color wash + gold-leaf faction emblem top-border.
   - Always fall back to CARD_ART_LOGO if missing.

3. **Art Ingestion Workflow**
   - Source remaining sets from Google Drive Product & DEV / _MΛĐHATs Gambit DEV / NFTCards* folders.
   - Use Drive tools to download base64 → decode to verify/public/cards/NNN.png.
   - Batches of ~12 recommended.
   - After drop: run node verify/scripts/gen-card-art.mjs → commit.

4. **Generation Pipeline**
   - FLUX LoRA lives in MAD-Card-Art-Generator (private).
   - Prefer original Drive art over regeneration unless founder requests new generations.
   - Never overwrite committed original art without explicit approval.

5. **Integration**
   - Coordinate with dopamine-ui-design-system for visual treatment consistency.
   - brand-enforcer for any logo / emblem assets.
   - production-readiness-gate for screenshot-diff of card renders.
   - mad-gambit-concierge for handoff of large art batches.

6. **Output**
   - Always report current CARD_ART_COUNT and missing serial ranges.
   - Provide exact Drive search queries and gen-card-art.mjs command.
   - Never invent art; only use or request real assets.
