# TEMPLATES/

Reusable structures. Study the shape, never copy the content.

| Folder | Holds |
|---|---|
| `pitch/` | Deck skeletons, hotsheet, one-pager layouts |
| `content/` | Blog, social, newsletter formats |
| `outreach/` | VC and partner email patterns |

Rule: never edit a template to fit one deliverable. Fork it into `OUTPUTS/`.
